# 新規事業・コンペ持ち込み整理

このドキュメントは、`やさしいAIオラクルカード` を会社の新規事業案として検討し、社内コンペや事業アイデア審査に持ち込むための整理です。  
現状の実装を「占いアプリ」として見せるだけでなく、AIを使った感情ケア・相談体験・有料コンテンツ導線の検証プロダクトとして説明することを狙います。

## 1. 事業アイデアの一言

恋愛や人間関係の悩みを抱えるユーザーに、AIが短時間で気持ちを整理するリーディングを返し、深掘り相談や有料コンテンツへつなげるモバイル特化の感情ケアサービス。

## 2. なぜ今やるのか

- 生成AIにより、個別文脈に合わせた相談・文章生成のコストが下がっている
- 恋愛・人間関係の悩みは検索、SNS、占い、相談サービスで継続需要がある
- ユーザーは「正解」よりも、気持ちを整理する短い言葉や次の行動を求める場面が多い
- 1枚引き、深掘り、3枚リーディングのような段階設計は、無料体験から有料体験への導線を作りやすい
- 現PJには、AI生成、フォールバック、イベント計測、購入導線、AB比較の土台がすでにある

## 3. ターゲット

### 初期ターゲット

- 20代後半から30代前半の女性
- 恋愛、復縁、連絡待ち、片思いなどの悩みを抱えている
- 長文相談より、スマホで短時間に気持ちを整理したい
- 占い・診断・心理テスト・恋愛コラムへの接触経験がある

### 利用シーン

- 返信が来ない夜に、行動する前の気持ち整理
- 相手の態度を深読みしてしまうときのセルフチェック
- SNSで結果を共有したいとき
- 有料記事や相談サービスに進む前のライトな入口

## 4. 解決する課題

| 課題 | 現PJでの解決方法 |
|---|---|
| 悩みを言語化できない | 診断4択とカード結果で状況を簡単に選べる |
| すぐ不安になって行動してしまう | 150〜260文字程度の短い読み解きと具体行動を返す |
| 無料体験だけで終わる | deep 2回制限と premium 導線で次の体験へ進める |
| 改善点が見えない | イベントDBとファネル集計でCVを確認できる |
| AI出力が不安定 | フォールバックと禁止語チェックで最低限の体験品質を担保する |

## 5. 事業仮説

### 仮説A: 無料リーディングは高い初回体験率を作れる

検証指標:

- `page_view_lp -> draw_completed`
- `draw_completed -> result_viewed`
- `result_viewed -> share_clicked`

### 仮説B: 深掘り回遊は有料導線への納得感を上げる

検証指標:

- `result_viewed -> deep_dive_opened`
- `deep_dive_opened -> deep_focus_selected`
- `deep_dive_opened -> premium_intro_viewed`

### 仮説C: 3枚リーディングは低単価課金に向いている

検証指標:

- `premium_intro_viewed -> premium_checkout_clicked`
- `premium_checkout_clicked -> purchase_success`
- `purchase_success -> purchase_completed`

### 仮説D: 診断タイプ別の訴求でCVが変わる

検証指標:

- 診断タイプ別の `result_to_premium_intro`
- 診断タイプ別の `checkout_to_purchase_completed`
- LPコピーABの variant 差分

## 6. 提供価値

### ユーザー価値

- 悩みを短時間で整理できる
- 次に取る行動を1つに絞れる
- 誰かに相談する前のクッションになる
- 占い・診断の楽しさと、現実的な行動提案を両立できる

### 会社側の価値

- AI相談体験の小さな検証基盤になる
- 記事、占い、相談、EC、コミュニティなど複数事業へ横展開できる
- CV計測とABテストを最初から組み込める
- 低コストでMVP検証しやすい

## 7. 収益モデル案

| モデル | 内容 | 優先度 |
|---|---|---|
| 単発課金 | 3枚リーディング、相手の気持ち、連絡タイミングなどを販売 | 高 |
| note連携 | 診断タイプ別の有料記事へ送客 | 高 |
| 月額 | 毎日リーディング、履歴、深掘り回数増加 | 中 |
| 相談送客 | 電話相談、チャット相談、カウンセリングへの送客 | 中 |
| 広告/タイアップ | 恋愛・美容・ライフスタイル商材との連携 | 低 |

初期は単発課金または note 連携で、実装・運用コストを抑えてCV検証するのが現実的です。

## 8. コンペで伝えるべきポイント

### 1. 既に動くMVPがある

- LP
- 1枚引き
- AIメッセージ生成
- 深掘り
- 有料導線
- イベント計測
- 日次/期間CV集計

### 2. 改善サイクルを回せる

画面を作って終わりではなく、`/api/events` と `/api/analytics/*` により、どこで離脱したかを確認できます。

### 3. AI失敗時も体験が止まらない

APIキー未設定や OpenAI API エラーでもフォールバック文を返すため、デモや検証環境で壊れにくいです。

### 4. 課金前後の整合性を考えている

`attemptId`、Webhook、TTL、重複防止により、外部checkoutの戻りURLだけを信用しない設計になっています。

### 5. 横展開できる

恋愛オラクルに限らず、以下へ転用できます。

- キャリア診断
- メンタルセルフケア
- 推し活診断
- 美容・ライフスタイル診断
- 社内人材マッチング/キャリア相談

## 10. ピッチ構成案

```text
1. 問題提起
   恋愛や人間関係の悩みは日常的だが、すぐ人に相談しにくい。

2. 解決策
   AIが短時間で気持ちを整理し、次の行動を1つ返す。

3. 体験
   診断 -> 1枚引き -> 結果 -> 深掘り -> 3枚リーディング。

4. 事業性
   単発課金、note連携、相談送客、月額化が可能。

5. 検証可能性
   イベント計測とファネル集計が実装済み。

6. 次にやること
   ターゲット検証、LP AB、価格検証、コンテンツ拡張。
```

## 11. 検証計画

### Phase 1: 需要検証

期間: 2週間

やること:

- LPコピーABテスト
- SNSや社内協力者への限定公開
- 体験後アンケート
- 診断タイプ別の利用率確認

見る指標:

- LP -> draw CV
- result 到達率
- deep 利用率
- share 率
- 自由記述の満足度

### Phase 2: 課金意向検証

期間: 2〜4週間

やること:

- 3枚リーディングの価格仮説を置く
- note または仮checkoutへの遷移を測る
- 有料説明ページのコピーAB
- 購入完了または購入意向アンケートを取る

見る指標:

- result -> premium intro
- premium intro -> checkout
- checkout -> purchase
- 診断タイプ別CV

### Phase 3: 継続価値検証

期間: 4週間

やること:

- 再訪計測
- 毎日リーディングの仮導線
- 結果履歴の価値検証
- 月額化の受容性ヒアリング

見る指標:

- revisit
- streakDays
- 2回目以降の deep 利用率
- 月額利用意向

## 12. リスクと対策

| リスク | 対策 |
|---|---|
| 占い表現が過度に依存を生む | 「断定しない」「行動は1つ」「医療/法律/危機相談に踏み込まない」ルールを設ける |
| AI出力が不適切 | 禁止語、出力形式、フォールバック、レビュー観点を整備する |
| 課金導線が弱い | 診断タイプ別の訴求、価格AB、サンプル表示を検証する |
| 個人情報を扱う懸念 | 初期MVPではログイン不要、相談本文を保存しない設計にする |
| 競合との差別化が弱い | 「感情ケア + 行動提案 + CV改善基盤」を軸にする |
